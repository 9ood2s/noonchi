# 경기도 초등 전보 규칙 (2027학년도) — 계산 근거

> 출처 = **2027학년도 경기도교육공무원인사관리세부기준(유치원·초등)** · 67차 개정 2026. 7. 28.
> 원자료 = `data/source/gyeonggi-2027-personnel-standards.pdf` (신구대비표도 같이 받아 뒀다)
> 2026-08-20 원문에서 추출. ⚠️ **매년 개정된다** — 학년도가 바뀌면 이 문서를 다시 뜬다.
> ⚠️ 아래는 계산기를 만들기 위한 정리다. **법적 해석이 아니다.**
>
> **학교별 인사구역은 사람이 옮겨 적지 않는다** — `npm run areas 2027` 이 표에서 직접 읽는다.
> **아래 계산 규칙은 `lib/transfer.mjs` 에 그대로 들어가 있고 `npm run selftest` 가 지킨다.**
> 규칙을 고치면 셀프체크가 먼저 깨져야 한다. 아래 「계산 예시」가 그 검사 중 하나다.

## 1. 전보년수 — 순위를 정하는 값

```
전보년수 = 현임교 근무년수 + 가산년수
```

전보희망자 순위명부는 **현임교 전보년수 순**으로 작성한다(**제13조 ①**).

⛔ **이 명부는 「시·군간(관외) 전보」의 것이다.** 원문이 이 명부를 쓴다고 **명시한 곳은 제11조 ⑥-1
(시·군간 일반전보) 하나뿐**이고, **관내 전보는 제24조가 「교육장이 원칙을 수립·실시한다」로 넘긴다.**
→ 즉 경기도 인천과 같은 구조다. **관내 전보 기준은 도 기준에 없고 교육지원청이 정한다.**
⚠️ 2026-08-23 까지 이 문서는 조문을 「제16조 ①」로 잘못 적고 있었다 — 제16조는
「교(원)감 및 교사 전보의 우대」(가산표)다. 그 탓에 이 값이 관내에도 쓰이는 것처럼 읽혔다
(`DESIGN.md §12-87-4`).

### 현임교 근무년수

- 월수까지 계산한다. **15일 이상 = 1월**, 15일 미만은 산입하지 않는다(제13조 ⑥).
- **2년 이상 근무해야 내신할 수 있다.** 하루라도 부족하면 내신 불가.
- 휴직·연수파견·기관파견 등 현임교에서 학생을 직접 지도하지 않은 기간은 제외한다(**휴가는 포함**).
- ⭐ **가산 계산에서 현임교 근무년수는 5년을 넘지 못한다.** 유예 기간도 산입하지 않는다(제11조 ④).

### 경합하면

전보년수 → 근무성적 다점자 → 생년월일 빠른 순(제13조 ⑦).

## 1-9. ⛔ 특구역은 없어졌다 (2026. 3. 1.)

부칙 제5조 — 「특구역 조정에 따른 **갑구역 지정은 2026년 3월 1일부터 시행**하며, 시행 전
제13조 2항에 특만기에 해당하는 자의 **특구역 근무 경력은 전보년수(가산점 포함)에 포함하지 아니한다**」

별표1을 세어 보면 2026·2027 문서 모두 **갑·을·병 셋뿐**이고 「특」은 0교다.
옛 특구역 학교는 이미 갑구역으로 들어가 있다.

⚠️ **남은 단서** — 2026년 3월 이전 특구역 근무 경력은 전보년수에 안 들어간다.
계산기는 현임교 근무년수를 그대로 받으므로, 그 기간을 빼고 넣어야 맞는다. 화면에 적어 뒀다.

## 2. 가산년수 — 세 표를 더한다

### 2-1. 지역가산표

| 구역 | 급지 | 가산 비율 |
|---|---|---|
| 병구역 | 가·나 | 현임교 근무년수 **100%** |
| 병구역 | 다·라 | **70%** |
| 을구역 | | **50%** |
| 5학급 이하 학교·분교장 | **구역 무관** | **30%** |

월수까지 계산하고 소수점 이하는 버린다.

⛔ **「갑구역은 지역가산이 없다」고 쓰지 않는다.** 표에 갑구역 줄이 없을 뿐이고,
「5학급 이하 학교·분교장 30%」 줄은 **구역을 가리지 않는다** — 갑구역이라도 5학급 이하면 30%다.
학급수는 **나이스 `classInfo`** 에서 온다(`scripts/fetch-classes.mjs`). 학급수를 아는 학교는 판정이 끝나고,
모르는 학교만 화면에 **"—"** 가 남는다.

**실증 — 군포 둔대초는 갑구역인데 5학급이라 지역가산 30%다.** 전에는 "갑구역은 없음"이라고 잘못 말했을 학교다.
경기 초등에서 5학급 이하는 넷 — 군포 둔대(갑) · 여주 흥천(을) · 화성 수기(을) · 이천 설성(을).
뒤 셋은 을 50% 와 5학급 30% 가 겹쳐서, 높은 쪽 50% 를 쓰고 "낮게 보면 30%" 를 같이 낸다.

⛔ **겹칠 때 무엇이 우선인지 원문에 없다.** 제16조 ③ 은 "가산표와 같이 가산 적용한다"고만 한다.
병구역 가·나는 법정 특수지(벽지)라 **대개 소규모교**여서 겹치는 게 드문 경우가 아니다.
높은 쪽을 쓰되 낮게 본 값도 화면에 같이 낸다. 확인되면 고친다.

다만 **기타가산표의 부부공무원도 같이 `전체` 가 됐다** — 표를 옮겨 적을 때 헷갈리는 자리다.

### ⚠️ 합산 상한 — 교사에게는 없다 (착각하기 쉬운 자리)

"합산 가산년수는 현임교 근무년수의 **100%를 초과할 수 없다**"는 문장이 이 기준에 있지만,
**제17조 ③ — 교장 전보 우대 조항이다. 교사(제16조)에게는 적용되지 않는다.**

교사에게 걸리는 상한은 다른 것 하나뿐이다 — 각 가산표에 붙은
**"현임교 근무년수는 5년을 초과할 수 없음"**(2025.7.14. 개정). 비율로 매기는 가산
(지역·부부공무원·다자녀 등)의 **기준값이 5년으로 묶인다**는 뜻이지, 합계 상한이 아니다.

⛔ 계산기에 100% 상한을 넣으면 **틀린 값이 나온다.**

### 계산 예시 — `npm run selftest` 가 이 값을 지킨다

을구역 학교에서 **4년** 근무 · 부장 **2년** · 6학년 담임 **1년** · 세 자녀 이상인 교사:

```
현임교 근무년수                        4년 0월
  지역가산 (을구역 50%)      4년 × 50% = 2년 0월
  업무가산 (부장 2년 × 3월)             6월
  업무가산 (6학년 담임 1년 × 3월)         3월
  기타가산 (세 자녀 이상 50%)  4년 × 50% = 2년 0월
                          가산년수 합 = 4년 9월
────────────────────────────────────────────
전보년수                              8년 9월
```

## 3. 인사구역 — 갑 / 을 / 병

- 근무 희망지·거리·교통·문화시설을 감안해 **별표로 지정**한다(제9조). 신설교는 3년 이내 '을'.
- ⭐ **갑구역 근무기간은 10년이고, 갑구역 만기자는 관내로 내신할 수 없다**(제10조 ①-2).
  → **만기가 되면 지원청 밖으로 나가야 한다.** 이 서비스의 주 사용자가 여기다.
- 교육지원청이 달라지면 전임 지원청의 갑구역 근무년수는 산입하지 않는다(제10조 ①-2의1).
- 정년까지 계속 근무 가능(제10조 ②) — 정년 2년 이하 교장·교감 · **58세 이상 교사** · 심한 장애인 등록 교사.
- 갑 만기 유예(제10조 ③) — **세 자녀 이상은 2년**. 연장 2회 이내, 합산 2년 초과 불가.

### ⭐ [별표1] 2027년 초등학교 인사구역 현황표 — 읽어 냈다

**학교별 갑/을/병 지정이 이 표에 있다.** 구조 = 교육지원청 → 시·군 → 인사구역 → (병구역은 급지) → 학교명 목록 → 학교수.

`npm run areas 2027` 이 읽는다. **2027학년도 초등 1,373교** (갑 893 · 을 452 · 병 28).
지원청 총계 · 시군 총계 · 구역별 학교수 세 겹이 다 맞아야 통과한다.

⚠️ **공공 API 에는 이 값이 없다.** 이 PDF 가 유일한 출처고, 매년 새로 나온다.

**⭐ 급지는 이 표 안에 있다.** 인계서에 「급지는 별표1 에 없으니 법정 특수지 고시를 따로 봐야 한다」고
적혀 있었으나 틀렸다 — **병구역 행에 급지 칸이 따로 붙어 있다.** 갑·을 행에는 없는데,
갑은 지역가산이 없고 을은 급지와 무관하게 50% 라 필요가 없다.

```
파주  병  가  대성동                          1     → 지역가산 100%
          나  마정, 탄현, 삼성, 장파, 군내, 통일   6     → 100%
          다  파평, 용연, 마지, 적서             4     → 70%
          라  파양, 연풍, 웅담, 적암             4     → 70%
```

### 표에 그림으로만 있는 것 둘 — 밑줄과 음영

표 머리의 범례 — `＿＿은 폐·휴교임, 음영은 2027학년도 신설예정교`.
**이 둘은 글자가 아니라 그림이라 `pdftotext` 가 통째로 버린다.** 그래서 폐교한 학교 이름은
표에 남는데 학교수에는 안 잡혀 개수가 어긋난다(2027학년도판 성남 갑은 이름 73개인데 학교수 72 — `대원` 이 폐교).

판독기는 PDF 를 벡터로 뽑아 이 둘을 되찾는다. 자세한 것은 `scripts/parse-personnel-areas.mjs` 머리말.

### 2026 → 2027 에서 무엇이 바뀌었나

`npm run areas:diff 2026 2027` 이 뽑아 준다. **인사구역·급지가 바뀐 학교 32곳.**

| 무엇 | 몇 곳 | 지역가산 |
|---|---|---|
| **을 → 갑** (신설교 3년 유예가 끝났다 — 제9조) | 28 | **50% → 없음** |
| **갑 → 을** (남양주 퇴계원·도제원) | 2 | **없음 → 50%** |
| **병-라 → 병-나** (김포 석정·월곶·하성·옹정) | 4 | **70% → 100%** |

⛔ **매년 이만큼 움직인다.** 학년도가 바뀌면 판독기를 다시 돌리고 이 표를 갱신한다.

## 4. 전보 절차

- **정기전보는 매년 3월 1일자.** 교사 전보는 동일교 **2년 이상 5년 범위**.
- **동일교 재직교사의 1/2을 초과해 전보 내신할 수 없다**(관내·외 불문, 제11조 ①).
  → 나가고 싶어도 학교 단위로 인원이 막힌다. **TO 추정에 이 상한이 들어가야 한다.**
- ⭐ **시·군간(관외) 일반전보는 1희망뿐이다**(제11조 ⑥-1).
  전보 희망 시·군별로 작성한 **전보희망자 순위명부에 등재된 순으로** 전보한다.
- 갑구역 근무 만기자는 **1·2·3·4 희망**을 쓴다(제11조 ⑥-2).
- 보건·사서·전문상담교사는 **3개 시·군 이내** 희망 가능.

## 5. ⭐ 이 서비스가 존재하는 이유가 여기 있다

**관외 전보는 1희망만 쓴다.** 순위명부는 전보년수 순이다.
그러면 **남들이 어디를 쓸지 모른 채 한 장을 던져야 한다** — 정보 비대칭이 최대인 구조다.

- 내 전보년수는 내가 안다(계산기).
- **모르는 것은 "그 학교에 나보다 전보년수 높은 사람이 몇이나 쓰나"** 하나뿐이다.
- 모의지원이 그 하나를 채운다.
