## 전국을 견디게 바꾼 것 — `lib/schools.ts`

- `LEVELS` 상수를 만들어 학교급을 스위치로. 시·도는 이미 `SOURCES` 가 스위치였다.
- `schoolByCode` 가 **시·도를 통째로 읽어 훑던 것**을 표준학교코드 색인 + 한 줄 조회로.
  길찾기 API 가 학교를 찾을 때마다 1,637행을 읽고 있었다.
- `schoolsOfOffice` — 지원청 하나는 아무리 커도 백 곳 남짓이라 **전국이 되어도 조회 크기가 안 변한다.**
- `newestStatYear` — 공시 연도를 세는 자리를 한 곳으로. 지도 데이터도 이걸 쓴다.
- `schoolCodesOf` — 정적 화면 목록은 **코드 한 컬럼만** 받는다.
- `warmIndex` — 빌드 때만 부른다. 전국이 되어 빌드가 버거워지면 `dynamicParams = true` 로 바꾸고
  이 줄을 지우면 요청받을 때 만드는 쪽으로 넘어간다. **고칠 것이 두 줄이다.**

## 잡은 것 둘

**① 사이트맵이 빈 채로 빌드를 통과했다.** Next 16 이 `generateSitemaps` 의 `id` 를 `Promise<string>`
으로 바꿨다. 기다리지 않으면 `undefined` 가 되는데 오류가 안 난다 — 빈 사이트맵 두 장이 만들어지고
빌드는 초록으로 끝난다. **줄 수를 세어 보고서야 알았다.** 못 알아본 번호면 던지게 고쳤다.
⚠️ 이 저장소의 **네 번째** 「조용히 잘린다」다 (Supabase 1,000행 · 나이스 5행 · 학교알리미 5행).

**② 고른 학교가 저 혼자 풀리고 있었다.** 지도의 「시·도를 바꾸면 다 들어오게 맞춘다」 효과가
들어오자마자 `setSelected(null)` 을 했는데, 그 효과는 `ready`·`wide` 로도 다시 돈다.
**창을 좁혔다 넓히면 보던 학교 상세가 닫혔다.** 헤드리스 크롬으로 눌러 보지 않았으면 못 잡았다.

## 되짚기 — 사장님이 「짜치는데」라고 하신 뒤

「문서처럼 생긴게 마음에 안듦」 · 「크롤러만 볼 수 있는 페이지로 만들 수는 없으려나」 ·
「앱과 같은 모양새라면 상관없음」.

- **클로킹은 안 된다** — 사람과 크롤러에게 다른 것을 내주면 색인에서 빠지고 애드센스도 거절된다.
  ⭐ 그런데 그럴 필요가 없었다 — **앱 안에서 `/school` 로 가는 링크가 한 줄도 없다.** grep 으로 확인했다.
  사용자 동선에서 빠져 있는 것은 완전히 정상이고, 사장님이 원하신 그림이 이미 그것이었다(§12-155-4).
- **앱 꼴로 다시 그렸다**(§12-155-3) — 지도 머리 띠 + 유리 판. 길잡이 줄 삭제, 학교 목록 접기.
  `components/school-map.tsx` 80줄이다. `map-screen.tsx` 를 끌어오지 않았다.
- **또 하나 잡았다** — 네이버 SDK 가 지도 칸에 `position: relative` 를 덮어써서 **높이가 0** 이 됐고
  `overflow:hidden` 이 타일을 잘라냈다. **타일은 다 받아져 있는데 화면에만 없었다**(§12-156-5).
  MapLibre 때 똑같이 당한 자리다.
- **알아낸 것** — NCP 지도 키가 **`127.0.0.1` 을 안 받는다**(§12-156-6). 로컬에서 지도를 보려면
  `http://localhost:3000` 이어야 한다. 우리 개발 주소 규칙과 부딪힌다.
