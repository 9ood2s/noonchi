# 2026-10-20 — 공개 소스의 운영 계정 분리

## 변경

- 대표 주소·OAuth 복귀·www redirect를 설치별 환경변수로 통일했다. 설정 없는 복사본은 원 운영 서비스로 연결하지 않는다.
- 관련 개인 서비스 링크는 명시적인 URL 설정이 있을 때만 표시한다.
- 특정 소유자 이메일에 관리자 권한을 주던 신규 설치 SQL을 제거했다. 로컬 관리자 seed는 가상 계정이다.
- 수집 스크립트의 환경 파일 처리를 통일하고 로컬 개발은 CLI에서 받은 loopback DB와 localhost origin만 사용한다.
- 문서·주석의 개인 이메일·운영 프로젝트 참조·개인 경로·비공개 대화 링크, 머신 캐시와 개인 도구 권한 설정을 제거했다.
- 빈 `.env.example`, MIT 라이선스, 별도 설치·보안·외부 자료 안내를 추가했다.

## 검증

- 기존 원문 판독·학교 매칭·계산 검사 72개·가드 4종, 배포 origin/redirect 검사 5개 통과.
- 신규 로컬 Supabase에서 migration 55개와 합성 seed 적용 성공. 익명 관리자 조회 권한 차단, 일반회원 0행·합성 관리자 1행 확인.
- 로컬 자격 증명만 사용한 `next build --webpack` 성공: 정적 페이지 6,461개 생성, TypeScript 검사 통과.
- 브라우저에서 계산기 렌더링과 비로그인 관리자 차단 확인. canonical·robots·사이트맵은 로컬 origin을 사용하며 원 운영 origin을 포함하지 않는다.
- 클라이언트 JS 46개에서 로컬 서버 전용 키 노출 0개 확인.
- 정리된 소스의 Gitleaks 검사 및 알려진 개인 식별자 검색 통과. 기존 Git 기록은 공개 배포본에서 제외한다.

## 한계

- 실제 NAVER Maps·Kakao·OAuth 제공자 호출은 기존 개인 키를 쓰지 않아 검증하지 않았다. 지도 키가 없는 첫 화면은 설정 오류를 표시한다.
- 기본 Turbopack 빌드는 이 실행 환경의 포트 생성 제한으로 실패해 Webpack으로 확인했다.
- 기존 ESLint/TypeScript 7 조합은 ESLint 초기화에 실패한다. 이번 변경에서 의존성 버전을 바꾸지 않았다.
- 기존 운영 서비스의 자격 증명·DB·배포·저장소 공개 설정은 변경하지 않았다. 공개 대상은 정리된 파일만 담은 별도 소스 배포본이다.
