# 원자료 (source)

## ⛔ 파일 이름은 **적용 학년도**로 통일한다

시·도마다 문서에 붙이는 연도가 다르다. **그대로 두면 1년 어긋난 기준을 나란히 쓰게 된다.**

| 시·도 | 문서가 스스로 붙이는 연도 | 예 |
|---|---|---|
| 경기 | **적용 학년도** | `2027학년도 …세부기준` (67차 개정 2026. 7. 28.) |
| 인천 | **고시 날짜** | `인사관리기준(2026.7.7. 개정)` — 내용은 **2027학년도 적용** |

→ 저장소 파일명은 **적용 학년도**로 맞춘다. 위 둘은 `gyeonggi-2027-…`, `incheon-2027-…` 로 나란히 둔다.

## 폴더 구조 — `시도 / 발행기관 / 적용학년도`

```
data/source/
  gyeonggi/
    sido/          ← 경기도교육청 본청
      2026/  standards.pdf  standards.txt
      2027/  standards.pdf  standards.txt  diff.pdf
  incheon/
    sido/          ← 인천광역시교육청 본청
      2027/  standards.hwpx  standards.pdf  diff.hwpx
    nambu/ 2027/  standards.pdf  diff.pdf
    bukbu/ 2027/  standards.pdf  diff.pdf
    seobu/ 2027/  standards.hwp  diff.hwp
```

| 이름 | 무엇 |
|---|---|
| `standards.*` | 기준 원문 |
| `diff.*` | 신구대조표 (무엇이 바뀌었나) |
| `standards.txt` | 원문에서 뽑아 둔 글자 (`pdftotext -layout`) |

⛔ **연도는 폴더다. 파일 이름에 안 적는다.** 이름에 적으면 매년 이름이 바뀌고 스크립트가
그 이름을 문자열로 조립하게 된다. 폴더로 두면 **이름은 늘 같고 연도만 갈아 끼운다.**

⛔ **`sido` 는 시·도교육청 본청**이고, 지원청은 **그 옆에 나란히** 선다 — 위아래가 아니다.
본청 기준과 지원청 세부기준은 서로 다른 문서이고 **개정 주기도 따로 돈다.**
인천은 시 기준 제24·25조가 급지·근무연한·가산점을 지원청에 넘긴다.

⛔ **주소를 손으로 적지 않는다.** `scripts/lib/source.mjs` 의 `needSource(시도, 기관, 학년도, 파일)`
한 곳을 쓴다. 없으면 **어디를 봐야 하는지 적고 던진다** — 원자료가 빠진 채로 도는 판독기는
0건을 「정상」으로 낸다(나이스 5행과 같은 종류의 사고다).

### 늘리는 법 — 폴더 하나를 더 만든다. 코드는 안 고친다

| 무엇이 생기면 | 어디에 둔다 |
|---|---|
| 인천 동부·강화 급지가 고시되면 | `incheon/dongbu/2027/` · `incheon/ganghwa/2027/` |
| 2028학년도 기준이 나오면 | `gyeonggi/sido/2028/` · `incheon/sido/2028/` |
| 서울을 열면 | `seoul/sido/2028/` |
| 경기 지원청 세부기준을 받으면 | `gyeonggi/suwon/2028/` 처럼 |

⚠️ **수시 개정**은 같은 학년도 폴더 안에서 원문을 갈아 끼우고, 그 신구대조표를 `diff.*` 로 둔다.
차수(경기 66차 → 67차)는 문서 안에 적혀 있으므로 폴더 이름에 넣지 않는다 — 넣으면
「적용 학년도가 같은데 폴더가 둘」이 되어 어느 것이 지금 것인지 알 수 없다.

## ⛔ 인천은 문서가 두 층이다 — 시교육청 + 교육지원청 다섯

시교육청 고시문에는 **급지 표가 없다.** 제24조가 「동일구역 내 학교의 급지 지정은 교육장이 조정한다」로
넘기기 때문이다. 교사가 전보 때 쓰는 **가·나·다 급지**는 **교육지원청이 따로 고시**한다(다섯 곳).
→ 인천은 시 고시문 하나만 받아서는 화면을 못 채운다. 지원청 다섯 곳을 다 받아야 한다.
자세한 것은 `docs/rules-incheon-2027.md §2-5`.

**형식이 제각각이다** — 시교육청은 `hwpx`, 남부·북부는 `pdf`, 서부는 `hwp`(OLE 복합문서).
셋 다 `npm run grades:incheon 2027` 한 줄이 읽는다. hwp 는 `scripts/lib/hwp5.mjs` 가 푼다.

## 어느 파일을 읽나 — **hwpx 가 있으면 hwpx 를 읽는다**

`pdftotext` 는 **밑줄(폐·휴교)과 음영(신설예정교)을 버린다.** 그 두 표시가 없으면 학교 이름은 표에 남는데
학교수에는 안 잡혀 개수가 어긋난다(예: 성남 갑은 이름 73개인데 학교수 72 — `대원` 이 폐교).
PDF 에서는 이걸 그림(짧은 가로선·칠한 사각형)으로 되찾아야 한다.

**hwpx 는 그럴 필요가 없다.** zip 안의 XML 이고, 밑줄은 `Contents/header.xml` 의
`<hh:charPr>` 안에 `<hh:underline type="BOTTOM" shape="SOLID">` 로 **명시돼 있다**
(인천 2027 고시문 기준 문자모양 118개 중 밑줄 12개). 음영은 `borderFill` 의 채우기다.

## 매년 새로 받는다

학년도가 바뀌면 새로 받아 `scripts/parse-personnel-areas.mjs` 를 다시 돌리고
`docs/rules-gyeonggi-2027.md` 를 갱신한다.

**2026 → 2027 에서 실제로 바뀐 것** — 병구역 급지는 김포 한 곳뿐이었다.
`석정 · 월곶 · 하성 · 옹정` 이 **라 → 나** 로 올라가 지역가산이 **70% → 100%** 가 됐다.

`pdftotext` 는 poppler 에 들어 있다 — `brew install poppler`.
